# Admin integration

Admin changes propagate immediately to the student portal because both surfaces use the same models:

| Admin action | Portal effect |
|---|---|
| Activate enrolment | Dashboard unlocks course workspace |
| Publish course material | Materials list updates |
| Record attendance | Attendance page updates |
| Publish assignment/results | Assignments/assessments update |
| Record payment | Payments/balance update |
| Issue certificate | Certificates download available |

Use **Physical enrolment** and **Course enquiries** under Academy in the admin sidebar.
